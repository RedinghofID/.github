# RedingenhofID

We starten met de ontwikkeling van **RedingenhofID**.

Het doel van dit project is om bestaande, versnipperde tools  
(zoals Access-databases, PowerShell-scripts en andere losse scripts)  
te consolideren tot één geïntegreerde webapplicatie.

Deze applicatie zal zorgen voor betere onderhoudbaarheid, consistentie  
en gebruiksgemak binnen de organisatie.
